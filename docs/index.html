FEATURES

Built for excellence

Every module, every pixel, every interaction — crafted with precision.

Blazing Performance

Optimised for high-refresh-rate gameplay with minimal CPU and GPU overhead. No lag, no stutter — just raw performance.

OneConfig Native

Deeply integrated with Polyfrost's OneConfig. Modules, HUDs, profiles and accounts — all accessible through one unified interface.

Integrated Music

MP3/FLAC playback with real-time spectrum analyser, lyrics display, album art and NetEase Cloud Music streaming built-in.

Customisable HUDs

PotionHUD, TargetHUD, MusicHUD and more. Reposition, rescale, blur and theme — every HUD is fully yours to control.

Profile System

Save complete configurations — modules, keybinds, HUD layouts — under named profiles. Switch playstyles with one click.

Account Manager

Seamlessly manage Microsoft and offline accounts. Switch, refresh tokens and play — all without leaving the game.
